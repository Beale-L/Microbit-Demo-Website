Website Challenges

How it works: HTML is what is on the page (index.html). CSS is how it looks (style.css). After every change, save the file and refresh the browser. If you're using the online playground, the page updates on its own.

Level 1: Make it Yours

  1. Change Your Name Here to your name.
  2. Rewrite the "About Me" sentence about yourself.
  3. In style.css, change --page-background to your favorite color.
  4. Change --button-color and --title-color too.

Level 2: Add more stuff

  1. Copy a <button> line and paste it below to make a third button. Change what it says.
  2. Make your new button purple by changing its class to fun-button purple.
  3. Change the message that pops up when you click it (the words inside alert('...')).
  4. Add a new picture. Find a picture online, right-click it, choose Copy Image Address, and paste it into a new <img src="...">.

Level 3: Styling

  1. Make your pictures into circles: set border-radius in the img section to 50%.
  2. Make buttons spin when your mouse goes over them: change scale(1.1) to rotate(10deg).
  3. Create your own button color. Copy this into the bottom of style.css: 
    .rainbow { background-color: hotpink; }
    Then use it in HTML: class="fun-button rainbow"
  4. Add a whole new card! Copy everything from <div class="card"> to its matching </div> and give it a new title, like "My Favorite Foods."

Challenge level

  1. Turn a button into a link to your favorite website: 
    <a class="fun-button" href="https://www.nasa.gov">Go to NASA</a>
  2. Give the page a gradient background. Replace the background-color line in body with: 
    background: linear-gradient(pink, lightblue);
  3. Make up your own challenge and show a friend!

Quick tips

  • Every <tag> needs a closing </tag> (except <img>).
  • Every CSS line ends with a semicolon ;
  • Every { needs a matching }
  • Quotes come in pairs: "like this"
  • Still stuck? Undo with Ctrl+Z (Windows) or Cmd+Z (Mac).
